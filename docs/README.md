## Соглашения

* **ДП** — *проектное допущение*: решение принято нами из-за нехватки информации и подлежит согласованию. Сводный список — в [11-roadmap.md, раздел «Решения, требующие согласования»](11-roadmap.md#решения-требующие-согласования-с-компанией).
* **MUST / SHOULD / WON'T** — обязательно в MVP / желательно, если хватит времени / не входит в MVP.
* Время в БД и API — **UTC**, формат ISO 8601 с суффиксом `Z`. В интерфейсе — часовой пояс площадки (по умолчанию `Asia/Almaty`, ДП).
* Идентификаторы сущностей — UUID, кроме `ticket_events`, `audit_log` (bigint identity).
* Правило кодов ответа: объект **вне области видимости** пользователя → `404 NOT_FOUND`; действие **запрещено ролью** над видимым объектом → `403 FORBIDDEN`.
* Все числовые «критерии готовности» — **целевые значения для проверки**, а не достигнутые результаты.

## Глоссарий

| Термин | Определение |
|---|---|
| Сервисная организация | Организация, оказывающая обслуживание. В MVP — ровно одна (`organizations.kind = 'service'`). |
| Клиентская организация | Владелец оборудования. Данные клиента изолированы от других клиентов. |
| Площадка | Физическое место размещения оборудования клиента. |
| Оборудование | Единица учёта: трансформатор, подстанция (КТП), распределительное устройство. |
| Цифровой паспорт | Карточка оборудования: характеристики, документы, QR, история обслуживания. |
| Заявка (ticket) | Запрос на обслуживание: корректирующий (неисправность) или плановый (по графику). |
| Отчёт о работах (work_report) | Диагностика, результат, чек-лист, запчасти, фото по заявке. Имеет ревизии. |
| Акт | PDF-документ, сформированный из отправленной ревизии отчёта. Версионируется. |
| Подтверждение | Нажатие клиентом кнопки «Подтвердить» в системе с фиксацией пользователя, времени и версии акта. **Не является электронной подписью** (ЭЦП/КЭП). |
| Часы SLA | Накопленное «активное» время заявки по правилам [07-sla-analytics.md](07-sla-analytics.md). |
| Demo-время (T0) | Фиксированный момент `2026-03-16T10:00:00Z`, относительно которого рассчитаны ожидаемые значения demo. |
